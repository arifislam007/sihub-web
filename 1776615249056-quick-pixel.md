# Sombhabona Innovation Hub - IT Training Website Plan

## Overview
Build a modern, high-converting website for an IT skill training center that showcases 8 courses (4 foundation + 4 advanced) with a functional contact form. The site must emphasize skill development, feature outstanding visual design, and provide excellent user experience.

## Project Structure
```
sombhabona-hub/
├── index.html          # Main HTML structure
├── styles.css          # Advanced CSS with animations & responsive design
├── script.js           # Interactive JavaScript functionality
├── contact.php         # Backend form handler (or email service)
├── assets/
│   ├── images/         # For course images, hero background, logos
│   └── icons/          # Custom SVG icons if needed
└── README.md           # Project documentation
```

## Core Features to Implement

### 1. **Navigation & Header**
- Sticky navbar with smooth scroll navigation
- Logo with gradient text effect
- Mobile-responsive hamburger menu
- Active link highlighting on scroll
- CTA button "Contact Us" in header

### 2. **Hero Section (Above the Fold)**
- Compelling headline: "Master In-Demand IT Skills"
- Subtitle highlighting both beginner & advanced courses
- Two prominent CTA buttons: "Explore Courses" & "Free Counseling"
- Animated floating tech icons (Python, Docker, AWS, Linux)
- Gradient orbs with blur effects for depth
- Immediate stats showcase (500+ students, 15+ mentors, 98% success)
- Dark theme with accent gradients (purple/cyan)

### 3. **Courses Showcase (Main Content)**
Two-column layout on desktop:

**Column 1: Foundation Courses**
- Card-based layout with icons
- Each course card includes:
  - Course title & brief description
  - Duration badge (1-3 months)
  - Mode indicator (Online/Offline)
  - Hover effects with transform
- Courses:
  1. Graphic Design & Freelancing
  2. Digital Marketing & Freelancing
  3. IT Support
  4. Basic Computer Operation

**Column 2: Advanced & Certification Courses**
- Distinct visual treatment (gradient border/bg)
- Premium positioning with rocket icon
- Courses:
  1. Linux Operation for Beginner
  2. RHCSA & RHCE Exam Preparation
  3. DevOps & Docker
  4. AWS Cloud for Beginner

Course cards should:
- Have skill-focused icons (paintbrush, bullhorn, headset, desktop, linux, redhat, infinity/docker, aws)
- Animate on scroll into view
- Feature micro-interactions on hover
- Display clear duration labels

## Design System

### Color Palette
```css
--primary: #6366f1 (Indigo)
--primary-light: #818cf8
--secondary: #0ea5e9 (Sky Blue)
--accent: #f59e0b (Amber)
--bg-dark: #0a0a0a
--bg-darker: #050505
--bg-card: #111111
--text-primary: #ffffff
--text-secondary: #a1a1aa
--success: #10b981
--danger: #ef4444
```

### Typography
- **Headings**: Inter (weights: 700, 800, 900)
- **Body**: Inter (weights: 400, 500, 600)
- **Accent**: Playfair Display for hero (optional)
- **Base size**: 16px, line-height 1.7

### Gradients
- Primary gradient: `linear-gradient(135deg, #6366f1, #0ea5e9)`
- Hero background: Deep space dark
- Glass effects: `rgba(20,20,20,0.8) + backdrop-filter blur`

### Effects
- Box shadows with colored glow
- Smooth transitions (cubic-bezier)
- Floating card animations
- Gradient text effects
- Grid overlay pattern
- Parallax scrolling on hero orbs

## Technical Implementation

### HTML Structure
- Semantic HTML5 (header, nav, section, article, footer)
- Proper ARIA labels for accessibility
- SEO meta tags (title, description, keywords)
- Open Graph tags for social sharing
- Favicon inclusion

### CSS Architecture
- CSS custom properties (variables) for theming
- Mobile-first responsive approach
- Flexbox & Grid for layouts
- BEM-style class naming where applicable
- Animation keyframes for entrance effects
- Media queries: 1200px, 992px, 768px, 480px

### JavaScript Modules
1. **Navbar module** - Scroll effects, active states
2. **Mobile menu** - Hamburger toggle, close on outside click
3. **Smooth scroll** - Anchor link navigation
4. **Stats counter** - Animated number counting
5. **FAQ accordion** - Expand/collapse logic
6. **Contact form** - Validation + submission handling
7. **Scroll animations** - IntersectionObserver fade-ins
8. **Parallax effects** - Hero orb movement, mouse parallax

## Form Backend & Future Setup

**Decision: Use PHPMailer with SMTP** (More reliable delivery)
- SMTP credentials will be configured by user
- Template code provided with placeholder values
- Easy to switch to standard mail() if needed

**Database Structure for Future Course Hosting:**
- Prepare MySQL tables for:
  1. `courses` - Course catalog with video support
  2. `course_modules` - Section/lesson organization
  3. `student_enrollments` - User course access
  4. `video_metadata` - Vimeo/YouTube/Wistia integration ready
- Includes sample data for 8 existing courses
- Admin panel preparation structure

**Note:** Database remains optional initially; site works fully static. Can be activated when adding recorded courses.

### Responsive Breakpoints
- Desktop: >1200px (full layout)
- Laptop: 992px - 1200px (adjusted grids)
- Tablet: 768px - 992px (stacked layouts)
- Mobile: <768px (single column, hamburger menu)
- Small mobile: <480px (minimal footer, adjusted typography)

## SEO Considerations

## Accessibility (A11Y)
- Proper contrast ratios (4.5:1 minimum)
- Focus states for keyboard navigation
- ARIA labels where needed
- Screen reader friendly form labels
- Skip to content link (optional)
- Reduced motion preference respect
